# Tạo RAG Tool cho câu chuyện khách mời


Alfred, Agent đáng tin cậy của các bạn, đang chuẩn bị cho buổi gala xa hoa nhất thế kỷ. Để sự kiện diễn ra suôn sẻ, Alfred cần truy cập nhanh thông tin cập nhật về từng khách mời. Hãy giúp Alfred bằng cách tạo một Tool Retrieval-Augmented Generation (RAG) tùy chỉnh, dựa trên dataset tùy chỉnh của ta.

## Tại sao dùng RAG cho buổi Gala?

Hãy tưởng tượng Alfred đang hòa mình giữa khách mời, cần nhớ lại chi tiết cụ thể về từng người trong chốc lát. Một LLM truyền thống có thể gặp khó khăn vì:

1. Danh sách khách mời đặc thù cho sự kiện và không có trong dữ liệu huấn luyện của model
2. Thông tin khách mời có thể thay đổi hoặc cập nhật thường xuyên
3. Alfred cần truy xuất chi tiết chính xác như địa chỉ email

Đây chính là lúc Retrieval Augmented Generation (RAG) phát huy sức mạnh! Kết hợp hệ thống truy xuất với LLM, Alfred truy cập thông tin chính xác, cập nhật về khách mời theo yêu cầu.

### Bước 2: Tạo Retriever Tool

Bây giờ, hãy tạo một Tool tùy chỉnh để Alfred tìm kiếm thông tin khách mời.

<hfoptions id="agents-frameworks">
<hfoption id="smolagents">

Chúng ta sẽ dùng `BM25Retriever` từ module `langchain_community.retrievers` để tạo retriever tool.

> [!TIP]
> <code>BM25Retriever</code> là điểm khởi đầu tuyệt vời cho truy xuất, nhưng để tìm kiếm ngữ nghĩa nâng cao hơn, bạn có thể cân nhắc dùng các retriever dựa trên embedding như từ <a href="https://www.sbert.net/">sentence-transformers</a>.

```python
from smolagents import Tool
from langchain_community.retrievers import BM25Retriever

class GuestInfoRetrieverTool(Tool):
    name = "guest_info_retriever"
    description = "Retrieves detailed information about gala guests based on their name or relation."
    inputs = {
        "query": {
            "type": "string",
            "description": "The name or relation of the guest you want information about."
        }
    }
    output_type = "string"

    def __init__(self, docs):
        self.is_initialized = False
        self.retriever = BM25Retriever.from_documents(docs)

    def forward(self, query: str):
        results = self.retriever.invoke(query)
        if results:
            return "\n\n".join([doc.page_content for doc in results[:3]])
        else:
            return "No matching guest information found."

# Initialize the tool
guest_info_tool = GuestInfoRetrieverTool(docs)
```

Hãy hiểu tool này từng bước: 
- `name` và `description` giúp agent hiểu khi nào và cách dùng tool này
- `inputs` định nghĩa các tham số mà tool kỳ vọng (trong trường hợp này, một truy vấn tìm kiếm)
- Ta đang dùng `BM25Retriever`, một thuật toán truy xuất văn bản hiệu quả không cần embeddings
- Phương thức `forward` xử lý truy vấn và trả về thông tin khách mời liên quan nhất

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage, HumanMessage, AIMessage
from langgraph.prebuilt import ToolNode
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import tools_condition
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

# Generate the chat interface, including the tools
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [guest_info_tool]
chat_with_tools = chat.bind_tools(tools)

# Generate the AgentState and Agent graph
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## The graph
builder = StateGraph(AgentState)

# Define nodes: these do the work
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# Define edges: these determine how the control flow moves
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # If the latest message requires a tool, route to tools
    # Otherwise, provide a direct response
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

messages = [HumanMessage(content="Tell me about our guest named 'Lady Ada Lovelace'.")]
response = alfred.invoke({"messages": messages})

print("🎩 Alfred's Response:")
print(response['messages'][-1].content)
```

Kết quả mong đợi:

```
🎩 Alfred's Response:
Lady Ada Lovelace is an esteemed mathematician and pioneer in computing, often celebrated as the first computer programmer due to her work on Charles Babbage's Analytical Engine.
```

Điều gì đang xảy ra ở bước cuối cùng này:
- Chúng ta khởi tạo một model Hugging Face bằng lớp `HuggingFaceEndpoint`. Chúng ta cũng tạo giao diện chat và gắn thêm các tools.
- Chúng ta tạo agent (Alfred) dưới dạng `StateGraph`, kết hợp 2 node (`assistant`, `tools`) bằng một edge
- Chúng ta yêu cầu Alfred truy xuất thông tin về khách mời tên "Lady Ada Lovelace"
