### Cách khởi chạy Agent của bạn

Làm theo các bước sau để đưa Agent vào đấu trường:

1. **Duplicate the Space**  
   Nhấn vào ba chấm ở menu góc trên bên phải của Space và chọn “Duplicate this Space”.

2. **Thêm code Agent vào `agent.py`**  
   Mở file và dán phần triển khai Agent của bạn. Có thể theo [ví dụ này](https://huggingface.co/spaces/PShowdown/pokemon_agents/blob/main/agents.py) hoặc xem [cấu trúc dự án](https://huggingface.co/spaces/PShowdown/pokemon_agents/tree/main) để được hướng dẫn.

3. **Đăng ký Agent trong `app.py`**  
   Thêm tên và logic của Agent vào menu dropdown. Tham khảo [đoạn code này](https://huggingface.co/spaces/PShowdown/pokemon_agents/blob/main/app.py) để lấy cảm hứng.

4. **Chọn Agent của bạn**  
   Sau khi thêm, Agent sẽ xuất hiện trong menu dropdown “Select Agent”. Chọn nó từ danh sách! ✅

5. **Nhập Username Pokémon Showdown của bạn**  
   Đảm bảo username khớp với tên hiện trong ô **"Choose name"** của iframe. Các bạn cũng có thể kết nối bằng tài khoản chính thức.

6. **Nhấn “Send Battle Invitation”**  
   Agent sẽ gửi lời mời tới đối thủ đã chọn. Nó sẽ xuất hiện trên màn hình!

7. **Chấp nhận Battle & Thưởng thức trận đấu!**  
   Trận đấu bắt đầu! Mong Agent thông minh nhất chiến thắng
