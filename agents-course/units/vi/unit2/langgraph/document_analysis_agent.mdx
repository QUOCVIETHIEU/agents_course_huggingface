# Graph Phân tích Tài liệu

Alfred xin được phục vụ. Với tư cách quản gia đáng tin cậy của Mr. Wayne, tôi đã ghi lại cách hỗ trợ Mr. Wayne với các nhu cầu tài liệu đa dạng của ông. Trong khi ông ấy đi xử lý... các hoạt động ban đêm, tôi đảm bảo mọi giấy tờ, lịch tập luyện và kế hoạch dinh dưỡng đều được phân tích và tổ chức đúng cách.

Trước khi rời đi, ông ấy để lại ghi chú với chương trình tập luyện trong tuần. Tôi sau đó nhận trách nhiệm lập **thực đơn** cho các bữa ăn ngày mai.

Cho các sự kiện tương tự trong tương lai, hãy tạo hệ thống phân tích tài liệu bằng LangGraph để phục vụ nhu cầu của Mr. Wayne. Hệ thống này:

1. Xử lý tài liệu dạng ảnh
2. Trích xuất văn bản bằng các mô hình thị giác (Vision Language Model)
3. Thực hiện tính toán khi cần (để minh họa Tools thông thường)
4. Phân tích nội dung và cung cấp tóm tắt ngắn gọn
5. Thực thi các hướng dẫn cụ thể liên quan đến tài liệu

## Định nghĩa State của Agent

State này phức tạp hơn những State ta đã thấy trước đây.
`AnyMessage` là lớp từ Langchain định nghĩa các message, và `add_messages` là toán tử thêm message mới nhất thay vì ghi đè bằng State mới nhất.

Đây là khái niệm mới trong LangGraph: ta thêm toán tử vào State để định nghĩa cách chúng tương tác với nhau.

```python
class AgentState(TypedDict):
    # The document provided
    input_file: Optional[str]  # Contains file path (PDF/PNG)
    messages: Annotated[list[AnyMessage], add_messages]
```

## Chuẩn bị Tools

```python
vision_llm = ChatOpenAI(model="gpt-4o")

def extract_text(img_path: str) -> str:
    """
    Extract text from an image file using a multimodal model.
    
    Master Wayne often leaves notes with his training regimen or meal plans.
    This allows me to properly analyze the contents.
    """
    all_text = ""
    try:
        # Read image and encode as base64
        with open(img_path, "rb") as image_file:
            image_bytes = image_file.read()

        image_base64 = base64.b64encode(image_bytes).decode("utf-8")

        # Prepare the prompt including the base64 image data
        message = [
            HumanMessage(
                content=[
                    {
                        "type": "text",
                        "text": (
                            "Extract all the text from this image. "
                            "Return only the extracted text, no explanations."
                        ),
                    },
                    {
                        "type": "image_url",
                        "image_url": {
                            "url": f"data:image/png;base64,{image_base64}"
                        },
                    },
                ]
            )
        ]

        # Call the vision-capable model
        response = vision_llm.invoke(message)

        # Append extracted text
        all_text += response.content + "\n\n"

        return all_text.strip()
    except Exception as e:
        # A butler should handle errors gracefully
        error_msg = f"Error extracting text: {str(e)}"
        print(error_msg)
        return ""

def divide(a: int, b: int) -> float:
    """Divide a and b - for Master Wayne's occasional calculations."""
    return a / b

# Equip the butler with tools
tools = [
    divide,
    extract_text
]

llm = ChatOpenAI(model="gpt-4o")
llm_with_tools = llm.bind_tools(tools, parallel_tool_calls=False)
```

## Các Nodes

```python
def assistant(state: AgentState):
    # System message
    textual_description_of_tool="""
extract_text(img_path: str) -> str:
    Extract text from an image file using a multimodal model.

    Args:
        img_path: A local image file path (strings).

    Returns:
        A single string containing the concatenated text extracted from each image.
divide(a: int, b: int) -> float:
    Divide a and b
"""
    image=state["input_file"]
    sys_msg = SystemMessage(content=f"You are a helpful butler named Alfred that serves Mr. Wayne and Batman. You can analyse documents and run computations with provided tools:\n{textual_description_of_tool} \n You have access to some optional images. Currently the loaded image is: {image}")

    return {
        "messages": [llm_with_tools.invoke([sys_msg] + state["messages"])],
        "input_file": state["input_file"]
    }
```

## Mẫu ReAct: Cách tôi hỗ trợ Mr. Wayne

Cho phép tôi giải thích cách tiếp cận trong Agent này. Agent tuân theo mẫu ReAct (Reason-Act-Observe)

1. **Reason** (lập luận) về các tài liệu và yêu cầu của ông ấy
2. **Act** (hành động) bằng cách dùng Tools phù hợp
3. **Observe** (quan sát) kết quả
4. **Repeat** (lặp lại) khi cần cho đến khi đáp ứng đầy đủ nhu cầu của ông ấy

Đây là triển khai đơn giản của một Agent bằng LangGraph.

```python
# The graph
builder = StateGraph(AgentState)

# Define nodes: these do the work
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# Define edges: these determine how the control flow moves
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # If the latest message requires a tool, route to tools
    # Otherwise, provide a direct response
    tools_condition,
)
builder.add_edge("tools", "assistant")
react_graph = builder.compile()

# Show the butler's thought process
display(Image(react_graph.get_graph(xray=True).draw_mermaid_png()))
```

Ta định nghĩa Node `tools` với danh sách Tools. Node `assistant` đơn giản là model với các Tools đã gắn (bound).
Ta tạo Graph với các Node `assistant` và `tools`.

Ta thêm Edge `tools_condition`, định tuyến đến `End` hoặc đến `tools` tùy thuộc việc `assistant` có gọi Tool hay không.

Bây giờ, ta thêm một bước mới:

Ta kết nối Node `tools` trở lại `assistant`, tạo thành vòng lặp.

- Sau khi Node `assistant` thực thi, `tools_condition` kiểm tra xem đầu ra của model có phải lời gọi Tool không.
- Nếu là lời gọi Tool, luồng hướng đến Node `tools`.
- Node `tools` kết nối trở lại `assistant`.
- Vòng lặp này tiếp tục miễn là model quyết định gọi Tools.
- Nếu phản hồi của model không phải lời gọi Tool, luồng hướng đến END, kết thúc quá trình.

## Điểm chính cần nhớ

Nếu muốn tạo quản gia phân tích tài liệu của riêng mình, đây là những điểm cần cân nhắc:

1. **Định nghĩa Tools rõ ràng** cho các nhiệm vụ cụ thể liên quan đến tài liệu
2. **Tạo bộ theo dõi State vững chắc** để duy trì ngữ cảnh giữa các lời gọi Tool
3. **Cân nhắc xử lý lỗi** khi Tools thất bại
4. **Duy trì nhận thức ngữ cảnh** về các tương tác trước đó (toán tử `add_messages` đảm bảo điều này)

Với những nguyên tắc này, các bạn cũng cung cấp được dịch vụ phân tích tài liệu xuất sắc xứng đáng với Wayne Manor.

*Tôi tin rằng lời giải thích này đã thỏa đáng. Giờ thì, xin thứ lỗi, áo choàng của Master Wayne cần được là ủi trước các hoạt động tối nay.*
