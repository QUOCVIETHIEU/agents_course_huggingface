# Các khối xây dựng của LangGraph

Để xây dựng ứng dụng với LangGraph, cần hiểu các thành phần cốt lõi. Hãy xem các khối xây dựng cơ bản tạo nên một ứng dụng LangGraph.

Một ứng dụng trong LangGraph bắt đầu từ **entrypoint**, và tùy quá trình thực thi, luồng đi đến hàm này hoặc hàm khác cho đến khi đạt END.

## 1. State

**State** là khái niệm trung tâm trong LangGraph. Nó đại diện mọi thông tin chảy xuyên suốt ứng dụng.

```python
from typing_extensions import TypedDict

class State(TypedDict):
    graph_state: str
```

State **do người dùng định nghĩa**, vì vậy cần thiết kế các trường cẩn thận để chứa mọi dữ liệu cần thiết cho quá trình ra quyết định!

> 💡 **Mẹo:** Hãy suy nghĩ kỹ thông tin nào ứng dụng cần theo dõi giữa các bước.

## 2. Nodes

**Nodes** là các hàm Python. Mỗi Node:
- Nhận State làm đầu vào
- Thực hiện một số thao tác
- Trả về các cập nhật cho State

```python
def node_1(state):
    print("---Node 1---")
    return {"graph_state": state['graph_state'] +" I am"}

def node_2(state):
    print("---Node 2---")
    return {"graph_state": state['graph_state'] +" happy!"}

def node_3(state):
    print("---Node 3---")
    return {"graph_state": state['graph_state'] +" sad!"}
```

Ví dụ, Nodes có thể chứa:
- **Gọi LLM**: Sinh văn bản hoặc đưa quyết định
- **Gọi Tools**: Tương tác với hệ thống bên ngoài
- **Logic điều kiện**: Xác định bước tiếp theo
- **Can thiệp của con người**: Nhận đầu vào từ người dùng

> 💡 **Thông tin:** Một số Node cần thiết cho toàn bộ workflow như START và END đã có sẵn trong LangGraph.


## 3. Edges

**Edges** kết nối các Node và định nghĩa các đường đi có thể qua Graph:

```python
import random
from typing import Literal

def decide_mood(state) -> Literal["node_2", "node_3"]:
    
    # Often, we will use state to decide on the next node to visit
    user_input = state['graph_state'] 
    
    # Here, let's just do a 50 / 50 split between nodes 2, 3
    if random.random() < 0.5:

        # 50% of the time, we return Node 2
        return "node_2"
    
    # 50% of the time, we return Node 3
    return "node_3"
```

Edges có thể là:
- **Trực tiếp (Direct)**: Luôn đi từ Node A đến Node B
- **Có điều kiện (Conditional)**: Chọn Node tiếp theo dựa trên State hiện tại

## 4. StateGraph

**StateGraph** là container chứa toàn bộ workflow của Agent:

```python
from IPython.display import Image, display
from langgraph.graph import StateGraph, START, END

# Build graph
builder = StateGraph(State)
builder.add_node("node_1", node_1)
builder.add_node("node_2", node_2)
builder.add_node("node_3", node_3)

# Logic
builder.add_edge(START, "node_1")
builder.add_conditional_edges("node_1", decide_mood)
builder.add_edge("node_2", END)
builder.add_edge("node_3", END)

# Add
graph = builder.compile()
```

Sau đó ta trực quan hóa!
```python
# View
display(Image(graph.get_graph().draw_mermaid_png()))
```
<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/basic_graph.jpeg" alt="Graph Visualization"/>

Nhưng quan trọng nhất là gọi (invoke):
```python
graph.invoke({"graph_state" : "Hi, this is Lance."})
```
đầu ra:
```
---Node 1---
---Node 3---
{'graph_state': 'Hi, this is Lance. I am sad!'}
```

## Tiếp theo là gì?

Trong phần tiếp theo, ta đưa các khái niệm này vào thực tiễn bằng cách xây Graph đầu tiên. Graph này cho phép Alfred nhận email, phân loại chúng, và soạn câu trả lời sơ bộ nếu chúng là email chính đáng.
