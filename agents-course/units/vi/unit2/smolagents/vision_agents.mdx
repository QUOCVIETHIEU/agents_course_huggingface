## Cung cấp ảnh ở đầu quá trình thực thi của Agent

> [!TIP]
> Các bạn có thể theo dõi code trong <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/smolagents/vision_agents.ipynb" target="_blank">notebook này</a> và chạy bằng Google Colab.

Với cách tiếp cận này, ảnh được truyền cho Agent lúc bắt đầu và lưu dưới dạng `task_images` cùng với task prompt. Agent sau đó xử lý các ảnh này trong suốt quá trình thực thi.

Hãy xét trường hợp Alfred muốn xác minh danh tính các siêu anh hùng đến dự tiệc. Cậu đã có một dataset ảnh từ các buổi tiệc trước kèm tên khách. Với ảnh của một vị khách mới, Agent so sánh với dataset hiện có và quyết định có cho vào hay không.

Trong trường hợp này, một vị khách đang cố vào, và Alfred nghi ngờ rằng người này có thể là The Joker giả dạng Wonder Woman. Alfred cần xác minh danh tính để ngăn bất kỳ ai không mong muốn vào.

Hãy xây ví dụ. Trước tiên, các ảnh được load. Trong trường hợp này, ta dùng ảnh từ Wikipedia để giữ ví dụ tối giản, nhưng hãy tưởng tượng các use case khả thi! 

```python
from PIL import Image
import requests
from io import BytesIO

image_urls = [
    "https://upload.wikimedia.org/wikipedia/commons/e/e8/The_Joker_at_Wax_Museum_Plus.jpg", # Joker image
    "https://upload.wikimedia.org/wikipedia/en/9/98/Joker_%28DC_Comics_character%29.jpg" # Joker image
]

images = []
for url in image_urls:
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/114.0.0.0 Safari/537.36" 
    }
    response = requests.get(url,headers=headers)
    image = Image.open(BytesIO(response.content)).convert("RGB")
    images.append(image)
```

Giờ đã có ảnh, Agent sẽ cho ta biết liệu một vị khách thực sự là siêu anh hùng (Wonder Woman) hay phản diện (The Joker).

```python
from smolagents import CodeAgent, OpenAIServerModel

model = OpenAIServerModel(model_id="gpt-4o")

# Instantiate the agent
agent = CodeAgent(
    tools=[],
    model=model,
    max_steps=20,
    verbosity_level=2
)

response = agent.run(
    """
    Describe the costume and makeup that the comic character in these photos is wearing and return the description.
    Tell me if the guest is The Joker or Wonder Woman.
    """,
    images=images
)
```

Trong lần chạy của tôi, đầu ra như sau, dù có thể khác trong trường hợp của bạn, như ta đã thảo luận:

        'Costume and Makeup - First Image': (

        ),
        'Costume and Makeup - Second Image': (
            'Dark suit with a flower on the lapel, holding a playing card.',

## Cung cấp ảnh với Dynamic Retrieval

> [!TIP]
> Các bạn có thể theo dõi code trong <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/smolagents/vision_web_browser.py" target="_blank">file Python này</a>

Cách tiếp cận trước rất hữu ích và có nhiều use case tiềm năng. Tuy nhiên, trong tình huống khách không có trong database, ta cần các cách khác để nhận diện họ. Một giải pháp khả thi là động truy xuất ảnh và thông tin từ nguồn bên ngoài, chẳng hạn duyệt web để tìm chi tiết.

Với cách tiếp cận này, ảnh được thêm động vào memory của Agent trong quá trình thực thi. Như ta biết, các Agents trong `smolagents` dựa trên class `MultiStepAgent`, là sự trừu tượng hóa của framework ReAct. Class này hoạt động theo chu kỳ có cấu trúc trong đó các biến và tri thức khác nhau được ghi log ở các giai đoạn khác nhau:

1. **SystemPromptStep:** Lưu system prompt.
2. **TaskStep:** Ghi lại truy vấn người dùng và mọi đầu vào được cung cấp.
3. **ActionStep:** Ghi nhận log từ hành động và kết quả của Agent.

Cách tiếp cận có cấu trúc này cho phép Agents tích hợp thông tin hình ảnh một cách động và phản hồi thích ứng với các tác vụ đang thay đổi. Dưới đây là sơ đồ ta đã thấy, minh họa quy trình workflow động và cách các bước khác nhau tích hợp trong vòng đời Agent. Khi duyệt web, Agent có thể chụp screenshot và lưu chúng dưới dạng `observation_images` trong `ActionStep`.

Để hoàn thành ví dụ này, ta cần một bộ Tools mới cho Agent. Ngoài ra, ta sẽ dùng Selenium và Helium — các công cụ tự động hóa Browser. Điều này cho phép ta xây một Agent duyệt web, tìm chi tiết về một vị khách tiềm năng và truy xuất thông tin xác minh. Hãy cài các Tools cần thiết:

Ta sẽ cần một bộ agent tools được thiết kế đặc biệt cho duyệt web, như `search_item_ctrl_f`, `go_back`, và `close_popups`. Các Tools này cho phép Agent hành xử như một người đang điều hướng web.

```python
@tool
def search_item_ctrl_f(text: str, nth_result: int = 1) -> str:
    """
    Searches for text on the current page via Ctrl + F and jumps to the nth occurrence.
    Args:
        text: The text to search for
        nth_result: Which occurrence to jump to (default: 1)
    """
    elements = driver.find_elements(By.XPATH, f"//*[contains(text(), '{text}')]")
    if nth_result > len(elements):
        raise Exception(f"Match n°{nth_result} not found (only {len(elements)} matches found)")
    result = f"Found {len(elements)} matches for '{text}'."
    elem = elements[nth_result - 1]
    driver.execute_script("arguments[0].scrollIntoView(true);", elem)
    result += f"Focused on element {nth_result} of {len(elements)}"
    return result


@tool
def go_back() -> None:
    """Goes back to previous page."""
    driver.back()


@tool
def close_popups() -> str:
    """
    Closes any visible modal or pop-up on the page. Use this to dismiss pop-up windows! This does not work on cookie consent banners.
    """
    webdriver.ActionChains(driver).send_keys(Keys.ESCAPE).perform()
```

Ta cũng cần chức năng lưu screenshot, vì đây sẽ là phần thiết yếu trong những gì Vision Agent dùng để hoàn thành tác vụ. Chức năng này bắt screenshot và lưu trong `step_log.observations_images = [image.copy()]`, cho phép Agent lưu và xử lý ảnh một cách động khi điều hướng.

```python
def save_screenshot(step_log: ActionStep, agent: CodeAgent) -> None:
    sleep(1.0)  # Let JavaScript animations happen before taking the screenshot
    driver = helium.get_driver()
    current_step = step_log.step_number
    if driver is not None:
        for step_logs in agent.logs:  # Remove previous screenshots from logs for lean processing
            if isinstance(step_log, ActionStep) and step_log.step_number <= current_step - 2:
                step_logs.observations_images = None
        png_bytes = driver.get_screenshot_as_png()
        image = Image.open(BytesIO(png_bytes))
        print(f"Captured a browser screenshot: {image.size} pixels")
        step_log.observations_images = [image.copy()]  # Create a copy to ensure it persists, important!

    # Update observations with current URL
    url_info = f"Current url: {driver.current_url}"
    step_log.observations = url_info if step_logs.observations is None else step_log.observations + "\n" + url_info
    return
```

Hàm này được truyền cho Agent dưới dạng `step_callback`, vì nó được kích hoạt ở cuối mỗi bước trong quá trình thực thi của Agent. Điều này cho phép Agent động bắt và lưu screenshot xuyên suốt quá trình.

Giờ ta có thể tạo Vision Agent để duyệt web, cung cấp cho nó các Tools ta đã tạo, cùng với `DuckDuckGoSearchTool` để duyệt web. Tool này giúp Agent truy xuất thông tin cần thiết để xác minh danh tính khách dựa trên tín hiệu hình ảnh.

```python
from smolagents import CodeAgent, OpenAIServerModel, DuckDuckGoSearchTool
model = OpenAIServerModel(model_id="gpt-4o")

agent = CodeAgent(
    tools=[DuckDuckGoSearchTool(), go_back, close_popups, search_item_ctrl_f],
    model=model,
    additional_authorized_imports=["helium"],
    step_callbacks=[save_screenshot],
    max_steps=20,
    verbosity_level=2,
)
```
