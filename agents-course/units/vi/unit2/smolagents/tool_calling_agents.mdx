# Viết Action dưới dạng đoạn code hoặc blob JSON

> [!TIP]
> Các bạn có thể theo dõi code trong <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/smolagents/tool_calling_agents.ipynb" target="_blank">notebook này</a> và chạy bằng Google Colab.

Tool Calling Agents là loại Agent thứ hai trong `smolagents`. Khác Code Agents dùng đoạn code Python, các Agents này **dùng khả năng gọi Tool tích hợp của các nhà cung cấp LLM** để sinh tool call dưới dạng **cấu trúc JSON**. Đây là cách tiếp cận chuẩn của OpenAI, Anthropic và nhiều nhà cung cấp khác.

Hãy xem một ví dụ. Khi Alfred muốn tìm dịch vụ catering và ý tưởng tiệc, một `CodeAgent` sẽ sinh và chạy code Python như sau:

```python
for query in [
    "Best catering services in Gotham City", 
    "Party theme ideas for superheroes"
]:
    print(web_search(f"Search for: {query}"))
```

Một `ToolCallingAgent` thay vào đó sinh cấu trúc JSON:

```python
[
    {"name": "web_search", "arguments": "Best catering services in Gotham City"},
    {"name": "web_search", "arguments": "Party theme ideas for superheroes"}
]
```

Blob JSON này sau đó dùng để thực thi các tool call.

Mặc dù `smolagents` chủ yếu tập trung vào `CodeAgents` vì [chúng hoạt động tốt hơn tổng thể](https://huggingface.co/papers/2402.01030), `ToolCallingAgents` hiệu quả với hệ thống đơn giản không cần xử lý biến hoặc tool call phức tạp.

![Code vs JSON Actions](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/code_vs_json_actions.png)  

## Tool Calling Agents hoạt động như thế nào?

Tool Calling Agents tuân theo cùng workflow multi-step như Code Agents (xem [phần trước](./code_agents) để biết chi tiết).

Điểm khác then chốt nằm ở **cách chúng cấu trúc Action**: thay vì code có thể thực thi, chúng **sinh đối tượng JSON chỉ định tên Tool và tham số**. Hệ thống sau đó **parse các hướng dẫn này** để thực thi Tools phù hợp.

## Ví dụ: Chạy một Tool Calling Agent

Hãy xem lại ví dụ khi Alfred bắt đầu chuẩn bị tiệc, nhưng lần này ta dùng `ToolCallingAgent` để làm nổi bật sự khác biệt. Ta xây Agent tìm kiếm web bằng DuckDuckGo, giống ví dụ Code Agent. Điểm khác duy nhất là loại Agent — framework xử lý phần còn lại:

```python
from smolagents import ToolCallingAgent, WebSearchTool, InferenceClientModel

agent = ToolCallingAgent(tools=[WebSearchTool()], model=InferenceClientModel())

agent.run("Search for the best music recommendations for a party at the Wayne's mansion.")
```

Khi các bạn xem trace của Agent, thay vì thấy `Executing parsed code:`, các bạn sẽ thấy nội dung tương tự như:

```text
╭─────────────────────────────────────────────────────────────────────────────────────────────────────────────────╮
│ Calling tool: 'web_search' with arguments: {'query': "best music recommendations for a party at Wayne's         │
│ mansion"}                                                                                                       │
╰─────────────────────────────────────────────────────────────────────────────────────────────────────────────────╯
```  

Agent sinh một tool call có cấu trúc mà hệ thống xử lý để tạo đầu ra, thay vì thực thi code trực tiếp như `CodeAgent`.

Giờ các bạn đã hiểu cả hai loại Agent, hãy chọn loại phù hợp với nhu cầu. Tiếp tục với `smolagents` để giúp buổi tiệc của Alfred thành công! 🎉
