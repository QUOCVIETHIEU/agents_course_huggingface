# Xây dựng Agents dùng code

Code Agents là loại Agent mặc định trong `smolagents`. Chúng sinh tool call bằng Python để thực hiện Action — biểu diễn hành động hiệu quả, biểu cảm và chính xác.

Cách tiếp cận tinh gọn giảm số Action cần thiết, đơn giản hóa thao tác phức tạp và cho phép tái sử dụng hàm code hiện có. `smolagents` cung cấp framework nhẹ để xây Code Agents, triển khai trong khoảng 1.000 dòng code.

![Code vs JSON Actions](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/code_vs_json_actions.png)
Đồ họa từ bài báo [Executable Code Actions Elicit Better LLM Agents](https://huggingface.co/papers/2402.01030)

> [!TIP]
> Nếu các bạn muốn tìm hiểu thêm về lý do Code Agents hiệu quả, hãy xem <a href="https://huggingface.co/docs/smolagents/en/conceptual_guides/intro_agents#code-agents" target="_blank">hướng dẫn này</a> từ tài liệu smolagents.

## Tại sao dùng Code Agents?

Trong quy trình multi-step Agent, LLM viết và thực thi Action, thường gồm các tool call bên ngoài. Cách tiếp cận truyền thống dùng JSON để chỉ định tên Tool và tham số dưới dạng chuỗi, **mà hệ thống phải parse để xác định Tool nào cần thực thi**.

Tuy nhiên, nghiên cứu cho thấy **các LLMs gọi Tool hoạt động hiệu quả hơn khi dùng code trực tiếp**. Đây là nguyên tắc cốt lõi của `smolagents`, như sơ đồ trên từ [Executable Code Actions Elicit Better LLM Agents](https://huggingface.co/papers/2402.01030).

Viết Action bằng code thay vì JSON mang lại một số ưu điểm then chốt:

* **Khả năng kết hợp (Composability)**: Dễ kết hợp và tái sử dụng Action
* **Quản lý đối tượng (Object Management)**: Làm việc trực tiếp với cấu trúc phức tạp như hình ảnh
* **Tính tổng quát (Generality)**: Biểu diễn mọi tác vụ có thể tính toán được
* **Tự nhiên với LLMs**: Code chất lượng cao đã có sẵn trong dữ liệu huấn luyện của LLM

## Code Agent hoạt động như thế nào?

![From https://huggingface.co/docs/smolagents/conceptual_guides/react](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/smolagents/codeagent_docs.png)

Sơ đồ trên minh họa cách `CodeAgent.run()` hoạt động, theo framework ReAct mà ta đã đề cập ở Unit 1. Lớp trừu tượng chính cho Agents trong `smolagents` là `MultiStepAgent` — khối xây dựng cốt lõi. `CodeAgent` là dạng đặc biệt của `MultiStepAgent`, như ta sẽ thấy trong ví dụ bên dưới.

Một `CodeAgent` thực hiện Action qua chu kỳ các bước; biến và kiến thức hiện có được đưa vào ngữ cảnh của Agent, giữ trong nhật ký thực thi:

1. System prompt lưu trong `SystemPromptStep`, truy vấn người dùng ghi trong `TaskStep`.

2. Sau đó, vòng lặp while sau được thực thi:

    2.1 Phương thức `agent.write_memory_to_messages()` ghi nhật ký của Agent thành danh sách [chat messages](https://huggingface.co/docs/transformers/main/en/chat_templating) mà LLM đọc được.
    
    2.2 Các messages này được gửi tới một `Model`; mô hình sinh một completion.
    
    2.3 Completion được parse để trích xuất Action — trong trường hợp của ta, đây phải là đoạn code vì ta đang làm việc với `CodeAgent`.
    
    2.4 Action được thực thi.
    
    2.5 Kết quả được ghi vào memory trong một `ActionStep`.

Ở cuối mỗi bước, nếu Agent có bất kỳ lời gọi hàm nào (trong `agent.step_callback`), chúng sẽ được thực thi.

### Dùng Custom Tool để chuẩn bị thực đơn

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/smolagents/alfred-menu.jpg" alt="Alfred chuẩn bị thực đơn"/>

Giờ ta đã chọn được playlist, cần tổ chức thực đơn cho khách. Một lần nữa, Alfred dùng `smolagents` để làm việc này. Ở đây, ta dùng decorator `@tool` để định nghĩa hàm tùy chỉnh làm Tool. Ta sẽ tìm hiểu chi tiết hơn về tạo Tool sau; hiện tại, chỉ cần chạy code là đủ.

Như các bạn thấy trong ví dụ bên dưới, ta tạo Tool bằng decorator `@tool` và đưa nó vào danh sách `tools`.

```python
from smolagents import CodeAgent, tool, InferenceClientModel

# Tool to suggest a menu based on the occasion
@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion (str): The type of occasion for the party. Allowed values are:
                        - "casual": Menu for casual party.
                        - "formal": Menu for formal party.
                        - "superhero": Menu for superhero party.
                        - "custom": Custom menu.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

# Alfred, the butler, preparing the menu for the party
agent = CodeAgent(tools=[suggest_menu], model=InferenceClientModel())

# Preparing the menu for the party
agent.run("Prepare a formal menu for the party.")
```

Agent sẽ chạy qua vài bước cho đến khi tìm ra câu trả lời. Việc nêu rõ các giá trị được phép trong docstring giúp định hướng Agent tới các giá trị đối số `occasion` thực sự tồn tại và hạn chế hallucination.

Thực đơn đã sẵn sàng! 🥗

### Dùng Python imports bên trong Agent

Ta đã có playlist và thực đơn, nhưng còn một chi tiết quan trọng cần kiểm tra: thời gian chuẩn bị!

Alfred cần tính xem mọi thứ sẽ sẵn sàng lúc nào nếu cậu ấy bắt đầu chuẩn bị ngay bây giờ, phòng trường hợp cần sự hỗ trợ từ các siêu anh hùng khác.

`smolagents` chuyên về các Agents viết và thực thi đoạn code Python, cung cấp thực thi trong sandbox để đảm bảo an toàn.

**Thực thi code có các biện pháp bảo mật nghiêm ngặt** — các import nằm ngoài danh sách an toàn định sẵn bị chặn theo mặc định. Tuy nhiên, các bạn có thể cho phép thêm import bằng cách truyền chúng dưới dạng chuỗi trong `additional_authorized_imports`.
Để biết thêm chi tiết về thực thi code an toàn, xem [hướng dẫn](https://huggingface.co/docs/smolagents/tutorials/secure_code_execution) chính thức.

Khi tạo Agent, ta dùng `additional_authorized_imports` để cho phép import module `datetime`.

```python
from smolagents import CodeAgent, InferenceClientModel
import numpy as np
import time
import datetime

agent = CodeAgent(tools=[], model=InferenceClientModel(), additional_authorized_imports=['datetime'])

agent.run(
    """
    Alfred needs to prepare for the party. Here are the tasks:
    1. Prepare the drinks - 30 minutes
    2. Decorate the mansion - 60 minutes
    3. Set up the menu - 45 minutes
    4. Prepare the music and playlist - 45 minutes

    If we start right now, at what time will the party be ready?
    """
)
```


Những ví dụ này chỉ là khởi đầu cho những gì các bạn có thể làm với Code Agents, và ta đã bắt đầu thấy tính hữu dụng của chúng trong việc chuẩn bị buổi tiệc.
Các bạn có thể tìm hiểu thêm về cách xây Code Agents trong [tài liệu smolagents](https://huggingface.co/docs/smolagents).

Tóm lại, `smolagents` chuyên về các Agents viết và thực thi đoạn code Python, cung cấp thực thi trong sandbox để đảm bảo an toàn. Nó hỗ trợ cả mô hình ngôn ngữ cục bộ và dựa trên API, giúp thích ứng với nhiều môi trường phát triển khác nhau.

Các bạn có thể thắc mắc — Alfred đã xây dựng một Agent như vậy bằng `smolagents` như thế nào? Bằng cách tích hợp nhiều Tools, cậu ấy tạo Agent như sau. Đừng lo về các Tools lúc này; ta sẽ có một phần riêng sau trong Unit này để đi sâu:

```python
from smolagents import CodeAgent, DuckDuckGoSearchTool, FinalAnswerTool, InferenceClientModel, Tool, tool, VisitWebpageTool

@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion: The type of occasion for the party.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

@tool
def catering_service_tool(query: str) -> str:
    """
    This tool returns the highest-rated catering service in Gotham City.
    
    Args:
        query: A search term for finding catering services.
    """
    # Example list of catering services and their ratings
    services = {
        "Gotham Catering Co.": 4.9,
        "Wayne Manor Catering": 4.8,
        "Gotham City Events": 4.7,
    }
    
    # Find the highest rated catering service (simulating search query filtering)
    best_service = max(services, key=services.get)
    
    return best_service

class SuperheroPartyThemeTool(Tool):
    name = "superhero_party_theme_generator"
    description = """
    This tool suggests creative superhero-themed party ideas based on a category.
    It returns a unique party theme idea."""
    
    inputs = {
        "category": {
            "type": "string",
            "description": "The type of superhero party (e.g., 'classic heroes', 'villain masquerade', 'futuristic Gotham').",
        }
    }
    
    output_type = "string"

    def forward(self, category: str):
        themes = {
            "classic heroes": "Justice League Gala: Guests come dressed as their favorite DC heroes with themed cocktails like 'The Kryptonite Punch'.",
            "villain masquerade": "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains.",
            "futuristic gotham": "Neo-Gotham Night: A cyberpunk-style party inspired by Batman Beyond, with neon decorations and futuristic gadgets."
        }
        
        return themes.get(category.lower(), "Themed party idea not found. Try 'classic heroes', 'villain masquerade', or 'futuristic Gotham'.")


# Alfred, the butler, preparing the menu for the party
agent = CodeAgent(
    tools=[
        DuckDuckGoSearchTool(), 
        VisitWebpageTool(),
        suggest_menu,
        catering_service_tool,
        SuperheroPartyThemeTool(),
	FinalAnswerTool()
    ], 
    model=InferenceClientModel(),
    max_steps=10,
    verbosity_level=2
)

agent.run("Give me the best playlist for a party at the Wayne's mansion. The party idea is a 'villain masquerade' theme")
```

Như các bạn thấy, ta đã tạo một `CodeAgent` với nhiều Tools giúp tăng cường chức năng của Agent, biến nó thành nhà tổ chức tiệc tối thượng sẵn sàng chia sẻ với cộng đồng! 🎉

### Kiểm tra Party Preparator Agent của ta với OpenTelemetry và Langfuse 📡

Khi Alfred tinh chỉnh Party Preparator Agent, cậu ấy mệt mỏi với việc debug các lần chạy. Agents, về bản chất, khó đoán và khó kiểm tra. Nhưng vì cậu ấy muốn xây Party Preparator Agent tối thượng và triển khai vào production, cậu ấy cần khả năng truy vết vững chắc để giám sát và phân tích sau này.

Một lần nữa, `smolagents` đến cứu trợ! Nó áp dụng chuẩn [OpenTelemetry](https://opentelemetry.io/) để instrument các lần chạy của Agent, cho phép kiểm tra và ghi nhật ký.
