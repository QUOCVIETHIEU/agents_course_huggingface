# Multi-Agent Systems

Hệ thống Multi-Agent cho phép **các Agents chuyên biệt cộng tác trên các tác vụ phức tạp**, cải thiện tính mô-đun, khả năng mở rộng và độ vững chắc. Thay vì dựa vào một Agent duy nhất, các tác vụ được phân phối giữa các Agents với năng lực khác nhau.

Trong **smolagents**, các Agents khác nhau được kết hợp để sinh code Python, gọi Tools bên ngoài, thực hiện web search, và nhiều hơn nữa. Bằng cách điều phối các Agents này, ta tạo các workflow phức tạp.

Một thiết lập điển hình có thể gồm:
- Một **Manager Agent** để ủy thác tác vụ  
- Một **Code Interpreter Agent** để thực thi code  
- Một **Web Search Agent** để truy xuất thông tin  

Sơ đồ dưới đây minh họa kiến trúc Multi-Agent đơn giản, trong đó một **Manager Agent** điều phối một **Code Interpreter Tool** và một **Web Search Agent**; Agent này đến lượt mình dùng các Tools như `DuckDuckGoSearchTool` và `VisitWebpageTool` để thu thập thông tin liên quan.

## Multi-Agent Systems trong thực tế  

Một hệ thống Multi-Agent gồm nhiều Agents chuyên biệt làm việc cùng nhau dưới sự điều phối của một **Orchestrator Agent**. Cách tiếp cận này cho phép các workflow phức tạp bằng cách phân phối tác vụ giữa các Agents với vai trò khác nhau.

Ví dụ, một **hệ thống Multi-Agent RAG** có thể tích hợp:  
- Một **Web Agent** để duyệt internet.  
- Một **Retriever Agent** để lấy thông tin từ knowledge bases.  
- Một **Image Generation Agent** để tạo hình ảnh.  

Tất cả các Agents này hoạt động dưới một orchestrator quản lý việc ủy thác tác vụ và tương tác.

### Trước tiên ta tạo một Tool để lấy thời gian vận chuyển bằng máy bay hàng hóa.

```python
import math
from typing import Optional, Tuple

from smolagents import tool


@tool
def calculate_cargo_travel_time(
    origin_coords: Tuple[float, float],
    destination_coords: Tuple[float, float],
    cruising_speed_kmh: Optional[float] = 750.0,  # Average speed for cargo planes
) -> float:
    """
    Calculate the travel time for a cargo plane between two points on Earth using great-circle distance.

    Args:
        origin_coords: Tuple of (latitude, longitude) for the starting point
        destination_coords: Tuple of (latitude, longitude) for the destination
        cruising_speed_kmh: Optional cruising speed in km/h (defaults to 750 km/h for typical cargo planes)

    Returns:
        float: The estimated travel time in hours

    Example:
        >>> # Chicago (41.8781° N, 87.6298° W) to Sydney (33.8688° S, 151.2093° E)
        >>> result = calculate_cargo_travel_time((41.8781, -87.6298), (-33.8688, 151.2093))
    """

    def to_radians(degrees: float) -> float:
        return degrees * (math.pi / 180)

    # Extract coordinates
    lat1, lon1 = map(to_radians, origin_coords)
    lat2, lon2 = map(to_radians, destination_coords)

    # Earth's radius in kilometers
    EARTH_RADIUS_KM = 6371.0

    # Calculate great-circle distance using the haversine formula
    dlon = lon2 - lon1
    dlat = lat2 - lat1

    a = (
        math.sin(dlat / 2) ** 2
        + math.cos(lat1) * math.cos(lat2) * math.sin(dlon / 2) ** 2
    )
    c = 2 * math.asin(math.sqrt(a))
    distance = EARTH_RADIUS_KM * c

    # Add 10% to account for non-direct routes and air traffic controls
    actual_distance = distance * 1.1

    # Calculate flight time
    # Add 1 hour for takeoff and landing procedures
    flight_time = (actual_distance / cruising_speed_kmh) + 1.0

    # Format the results
    return round(flight_time, 2)


print(calculate_cargo_travel_time((41.8781, -87.6298), (-33.8688, 151.2093)))
```

### Thiết lập Agent

Với nhà cung cấp mô hình, ta dùng Together AI, một trong những [inference providers mới trên Hub](https://huggingface.co/blog/inference-providers)!

GoogleSearchTool dùng [Serper API](https://serper.dev) để tìm kiếm trên web, nên cần hoặc đã thiết lập biến môi trường `SERPAPI_API_KEY` và truyền `provider="serpapi"`, hoặc có `SERPER_API_KEY` và truyền `provider=serper`.

Nếu các bạn chưa thiết lập bất kỳ nhà cung cấp Serp API nào, hãy dùng `DuckDuckGoSearchTool` nhưng lưu ý rằng nó có rate limit.

### ✌️ Chia tác vụ giữa hai Agents

Cấu trúc Multi-Agent cho phép tách memory giữa các tác vụ con khác nhau, với hai lợi ích lớn:
- Mỗi Agent tập trung hơn vào tác vụ cốt lõi, do đó hiệu năng tốt hơn
- Tách memory giảm số lượng input tokens ở mỗi bước, do đó giảm latency và chi phí.

Hãy tạo một team với một web search Agent chuyên dụng, được quản lý bởi một Agent khác.

Manager Agent cần có khả năng vẽ biểu đồ để viết báo cáo cuối: vậy hãy cho nó quyền truy cập các import bổ sung, gồm `plotly`, và `geopandas` + `shapely` cho vẽ không gian.

```python
model = InferenceClientModel(
```

```python
from smolagents.utils import encode_image_base64, make_image_url
from smolagents import OpenAIServerModel


def check_reasoning_and_plot(final_answer, agent_memory):
    multimodal_model = OpenAIServerModel("gpt-4o", max_tokens=8096)
    filepath = "saved_map.png"
    assert os.path.exists(filepath), "Make sure to save the plot under saved_map.png!"
    image = Image.open(filepath)
    prompt = (
        f"Here is a user-given task and the agent steps: {agent_memory.get_succinct_steps()}. Now here is the plot that was made."
        "Please check that the reasoning process and plot are correct: do they correctly answer the given task?"
        "First list reasons why yes/no, then write your final decision: PASS in caps lock if it is satisfactory, FAIL if it is not."
        "Don't be harsh: if the plot mostly solves the task, it should pass."
        "To pass, a plot should be made using px.scatter_map and not any other method (scatter_map looks nicer)."
    )
    messages = [
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": prompt,
                },
                {
                    "type": "image_url",
                    "image_url": {"url": make_image_url(encode_image_base64(image))},
                },
            ],
        }
    ]
    output = multimodal_model(messages).content
    print("Feedback: ", output)
    if "FAIL" in output:
        raise Exception(output)
    return True


manager_agent = CodeAgent(
    model=InferenceClientModel("deepseek-ai/DeepSeek-R1", provider="together", max_tokens=8096),
    tools=[calculate_cargo_travel_time],
    managed_agents=[web_agent],
    additional_authorized_imports=[
        "geopandas",
        "plotly",
        "shapely",
        "json",
        "pandas",
        "numpy",
    ],
    planning_interval=5,
    verbosity_level=2,
    final_answer_checks=[check_reasoning_and_plot],
    max_steps=15,
)
```
